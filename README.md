# Data Analysis Projects

This repository collects small data analysis projects exploring different datasets, techniques and presentation approaches.

Each project includes its own documentation, data, and scripts used for analysis.

## Repository Structure

```
data_analysis/
├── README.md
├── example_project/
│ ├── README.md
│ ├── data/
│ ├── scripts/
│ ...
```

- **README.md**: overview of each project
- **data/**: raw or processed datasets
